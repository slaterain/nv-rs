THIRD-PARTY NOTICES — nv-rs (nv-viewer)

This file indexes the license texts of the 243 external packages in the repository's root Cargo.lock, which nv-viewer is built from (the build-time macro crates and every platform variant included): the 118 the Windows build draws on, and 125 that only the Linux and macOS builds use (winit, the game's window there, and what it brings). Package names, versions and license expressions come from each package's Cargo.toml in the local Cargo registry; the files were copied from that exact version there. A package that ships no license file gets the standard text of its license expression (MIT with its authors as the copyright line), marked in its entry. It ends with the notices of source code the translation followed that is not a package.

Files are bundled under licenses/<package>-<version>/ in release ZIPs (distribution/licenses/ in the source tree). No crate source or game assets are included.
